Shorter notes on other systems I've built. Clients are described by country and industry.

Call-QA platform for an Irish insurance brokerage

I built this end to end at my previous company. Dialer recordings are pulled in, transcribed with Whisper, and scored by an LLM against a versioned sales-script knowledge base, with separate portals for managers and executives. Scoring sits behind a provider-agnostic adapter (OpenAI or Anthropic). Every score stores the model, temperature and knowledge-base version, and the system refuses to score against an incomplete rubric. An executable suite checks 27 acceptance criteria against golden transcripts. Managers' edits to coaching emails are summarised weekly into versioned prompt adjustments, leaving the base rubric untouched.

  • Whisper
  • OpenAI and Claude APIs
  • Fastify
  • Next.js
  • Postgres with RLS
  • AWS CDK
  • ECS Fargate

AI sales platform for an Irish B2B supplier

I was the sole engineer on this €31k platform and built it in about 6 weeks with Node, Express, React and TypeScript. It takes in about 2,000 website-visitor companies, removes existing ERP customers with a 5-pass identity resolver, scores leads from 0 to 100, and drafts outreach that a person approves before anything is sent. Lead-discovery agents keep the evidence behind every lead and are constrained never to invent company names. The talk-to-your-ERP assistant is part of this platform.

  • Node.js
  • Express
  • React
  • TypeScript
  • OpenAI structured outputs
  • Supabase
  • Docker

WhatsApp nutrition coach for about 49 Irish gyms

The AI drafts replies to gym members on WhatsApp using retrieval. I built the responsive review dashboard (React, TypeScript, Tailwind, Supabase Realtime) where the coach approves, edits or skips each draft, and every edit is kept as training signal. Every 15 minutes a job diffs each AI draft against the coach's edit and sorts the changes into 5 failure categories, and factual corrections feed back into the live prompt. I also designed an LLM-as-judge quality loop with a pgvector gold corpus and a versioned rubric, where any rubric change the model proposes needs human approval.

  • React
  • Supabase Realtime
  • RAG
  • pgvector
  • LLM-as-a-judge
  • n8n
  • WhatsApp API

41 live n8n agent workflows

Across 6 client systems at my previous company I built LLM agents in 41 live n8n workflows. They use n8n's LangChain nodes: the AI Agent node with tool calling, structured and auto-fixing output parsers, Postgres chat memory and Supabase vector-store retrieval, on OpenAI and Anthropic models, triggered by webhooks. I used LangChain only through these n8n nodes. I also built the agency's QA platform for these automations, which adds execution logging to live workflows without changing their behaviour across 5 client systems and runs a nightly evaluation funnel with Claude.

Admin platform for an Irish financial-advice firm

As sole engineer I built a React, TypeScript and Supabase CRM with 30 schema migrations and 36 n8n workflows that connect SharePoint, Google Docs, Adobe Sign and other tools. GPT-4.1 drafts regulated suitability letters from client fact-find data, advisors edit them in the app, and a pipeline renders signature-ready documents. A 77-assertion simulator runs the production workflow code offline and fails if the letter template contract breaks.
